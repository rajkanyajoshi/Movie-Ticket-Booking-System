# Movie Ticket Booking System

This is a simple Movie Ticket Booking System developed using HTML, CSS, JavaScript and Bootstrap.

## Features
- Movie selection
- Show time selection
- Seat selection
- Ticket receipt generation

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap

## Project Flow
1. User opens the homepage
2. User clicks "Book Now"
3. User fills the booking form
4. User selects seats
5. System generates booking receipt
